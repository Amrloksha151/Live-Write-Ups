## Initial Noise Reduction

The dashboard showed a flood of failures, but most of them were harmless retries. I focused on the one event that could explain the timing of the first successful pivot.

```bash
grep -R "error" /var/log/app | tail -n 20
```

The first clue was a path traversal attempt that appeared only after a debug endpoint had been enabled.

## Correlating the Timeline

Once the noise was reduced, the same user agent appeared in three places: the build logs, the web server access logs, and the auth failures.
