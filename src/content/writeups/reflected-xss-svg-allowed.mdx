<Stage title="The Brief" description="Analyzing the search functionality">

## The Mission

The target application features a search function that reflects user input. However, a Web Application Firewall (WAF) is in place, blocking common XSS payloads. Your objective is to find a way to execute `alert(1)` by bypassing these filters.

**Constraints**:
- **Strict Filtering**: Common HTML tags like `<script>`, `<img>`, and `<body>` are explicitly blocked.
- **Modern Context**: The application supports embedded media and vector graphics.

<KnowledgeNote term="Reflected XSS" definition="A type of Cross-Site Scripting where the malicious script is 'reflected' off a web application to the victim's browser, typically via a URL parameter.">
  In this lab, the reflection point is the search query parameter.
</KnowledgeNote>

</Stage>

<Stage title="Initial Recon" description="Probing the WAF boundaries">

## Testing the Waters

First, we need to confirm the presence of the filter and identify what it's looking for.

<Stage title="Event Discovery" description="Finding the execution trigger">

## Pinpointing the Event Handler

Knowing `<animatetransform>` is allowed isn't enough; we need an event handler that the WAF also permits. We'll run another Intruder attack, this time targeting event attributes.

<CommandBuilder
  base="Payload Construction"
  target="<svg><animatetransform §event§=1>"
  options={[
    { flag: "onbegin", label: "onbegin", desc: "Triggers when the animation starts" },
    { flag: "onload", label: "onload", desc: "Triggers when the element loads" },
    { flag: "onclick", label: "onclick", desc: "Requires user interaction" }
  ]}
/>

<DecisionPoint
  question="If 'onbegin' returns a 200 OK while 'onload' returns a 400, which one should you use?"
  chosen="onbegin"
  reason="It is the only allowed event handler that triggers automatically without requiring user interaction."
  alternatives={["onclick", "onmouseover", "onerrror"]}
/>

</Stage>

<Stage title="Exploitation" description="Executing the final payload">

## The Final Strike

We combine the allowed tag and the allowed event handler. We also need to specify the `attributeName` for the animation to be valid.

<div class="terminal glass bg-black/80 rounded-lg p-4 font-space-mono text-sm border border-frost/20 mb-6">
  <div class="text-neon-cyan">/?search=%3Csvg%3E%3Canimatetransform+onbegin%3Dalert(1)+attributeName%3Dtransform%3E%3C%2Fsvg%3E</div>
</div>
